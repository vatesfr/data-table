# i18n

`DataTableLabels` in `packages/core/src/types.ts` defines static string keys and formatting functions (`formatCount(n)`, `rowCount(filtered, total)`, `groupCount(n)`, `groupLabel(index)`, `rowsInGroup(n)`, `selectGroup(group)`, `selectRow(row)`, `pageOf(page, total)`, `moreValues(n)`). `DEFAULT_LABELS` is English. Every adapter accepts a `labels?: Partial<DataTableLabels>` prop/option that is shallow-merged over the defaults.

- `formatCount(n)` groups digits (`toLocaleString` with the locale's tag: `10,010`, `10 010` with U+202F in French, `1234` ungrouped in Spanish). Each built-in locale's `rowCount`/`groupCount`/`rowsInGroup`/`moreValues` call that locale's own formatter, and the filter checklist calls `labels.formatCount`: overriding `formatCount` alone changes the checklist, not the built-in labels, and a custom `rowCount` formats its own numbers.

Built-in locales live in `packages/core/src/locales.ts` and are re-exported from every adapter package via a `@vates/data-table-core/locales` sub-path export — consumers import from `@vates/data-table-react`/`-vue`/`-solid`/`-vanilla` directly. Adding a new locale to `locales.ts` makes it available from every adapter with no further changes.
