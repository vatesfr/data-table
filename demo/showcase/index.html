data-table showcase

The same library in six very different apps: each page has its own data, interactions and look, and shows its source. All are built with the Solid adapter; the same API exists for React, Vue and plain JavaScript.

  • Fleet console

    1,500 virtual machines, dark monospace ops console, live CPU.

    • Grouping with totals, log-scale disk buckets
    • Bulk actions on a selection kept across live updates
    • Column categories, all-of tag filter

  • Grand livre

    Bank transactions as a printable French report.

    • French locale, monthly groups with sums
    • Range presets, excluded values
    • Read-only report styling

  • Event log

    100,000 log events in a dense viewer.

    • Search and filters at scale, pagination
    • Shareable view in the URL
    • Severity ordering, error rows highlighted

  • Product catalog

    A store back office, airy and brand-colored.

    • The page's own search and category chips drive the table
    • Row click opens a detail panel
    • Table or card view from the same state

  • Season stats

    Player statistics, wide and numeric.

    • Computed columns, multi-column sort
    • Team groups with averages and a custom aggregate
    • Pinned player column, sideways scrolling

  • User directory

    An admin screen for accounts and roles.

    • Saved views menu, view kept across reloads
    • Language switch for the table's built-in labels
    • Bulk actions, keyboard selection
Per-framework feature demos: React · Vue · Solid · Vanilla
